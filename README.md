# THis repository will contain projects that test my programming and technical skills :

---
### [Terminal Banking System on Python](banking-system-python)
An educational Python terminal application for practising object-oriented programming, custom exceptions, JSON file handling, password hashing, and automated testing. The system allows one local user to create accounts, make deposits and withdrawals, transfer money, and review transaction history.

---
### [Linear Algebra in Python and C++](linear-algebra)
Linear algebra equations implemented using Python and C++. The current example is a Leontief input-output model in Python with NumPy, interactive terminal input, a warning for non-square consumption matrices, and a table showing total demand and final demand.
